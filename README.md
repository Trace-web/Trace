# Trace Website

Responsive single-page product website for Trace, designed for GitHub Pages.

## Publish
1. Create a separate repository, e.g. `trace-website`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
5. GitHub Pages will show the public website URL when deployment finishes.

## Before launch
- Replace `REPLACE-WITH-YOUR-SUPPORT-EMAIL` with an email you control.
- Add the real Lemon Squeezy checkout URL to `PURCHASE_URL` in `index.html`.
- Confirm that every advertised feature is in the version you sell.
- Create accurate `privacy.html` and `terms.html` pages before launch.
- Add real screenshots when ready.
- Update the planned A$4.99 price if it changes.
- Do not put Trace's Python source code or private licence-signing keys in this website repository.
